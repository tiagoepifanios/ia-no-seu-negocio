# IA no Seu Negócio — página de vendas

Site estático para GitHub e Vercel. Não requer instalação, banco de dados ou build.

1. Envie o conteúdo desta pasta para a raiz de um repositório GitHub (index.html, style.css, script.js e a pasta assets).
2. Na Vercel, crie um projeto importando o repositório. Se solicitado, escolha Framework Preset: Other e deixe build e output em branco.
3. Faça o deploy e abra o endereço gerado. Teste os botões no celular e no computador.
4. Na Kiwify, altere a página de vendas para o endereço publicado, conforme as configurações do produto.

O link de checkout está no index.html. A página preserva UTMs no link, mas não instala Pixel nem API de Conversões. Configure a medição separadamente na Meta e na Kiwify e teste os eventos antes de anunciar. Não insira o PDF completo no repositório público; as imagens são apenas capa e amostras.
